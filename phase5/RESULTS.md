# Phase 5 results

We replayed the original iteration-200 adapter and a four-step continuation on all 16 frozen validation prompts. Both runs used the same FP16 expansion of the pinned 4-bit Gemma base, temperature zero, 1,536-token limit and validation code. We checked the file and every loaded adapter tensor separately for each arm. Timing covers generation and prompt processing on the CPU and excludes model loading. The jobs ran concurrently, so timing is descriptive and sensitive to contention.

| Development measure | Iteration 200 | Phase 5 candidate |
| --- | ---: | ---: |
| Structurally complete with valid citation references | 16/16 (100%) | 10/16 (62.5%) |
| Complete drafts containing at least one inline citation marker | 0/16 | 5/16 |
| Median generation time | 94.64 s | 67.51 s |
| Independent human ratings | 0 | 0 |

The candidate lost 37.5 percentage points of completeness. Four outputs had unparseable JSON (Hoka, Hydrow, Quip, Tatcha); only Hydrow actually hit the token limit. The email body failed schema validation in two further cases (Merit Beauty and Skims). Five complete candidate drafts included a citation marker within a field, but the mere presence of a marker says nothing about whether the passage supports the claim.

The [three-case evidence review](FAILURE_REVIEW.md) found that the revised model could replace one unsupported premise with another. The Blue Bottle candidate, for example, cited a passage about coffee and cafés to justify an email-marketing criticism. This experiment does not establish an improvement in factual grounding or send-readiness. **Keep iteration 200 as the default.** A next experiment should vary the mix of corrected and original training examples and evaluate gap validity with independent reviewers. The loss of completeness is an observed result; these runs cannot isolate its cause.

All 32 original responses and their validation records are under [results](results), with matched prompts referenced by hash in the committed validation dataset. [summary.json](results/summary.json) is regenerated by the comparison command in [README.md](README.md). The 33 held-out companies remain reserved for a frozen final evaluation. No outreach was sent.

To prepare a fresh blinded packet for independent reviewers:

```sh
python -m phase5.blind_review phase5/results/iteration200 phase5/results/candidate outputs/phase5/review
python evaluate_phase4.py preference --review-file outputs/phase5/review/blind_review.json --key outputs/phase5/review/private_key.json --out outputs/phase5/review/preference.json
```

Distribute only the worksheet to reviewers. Score the returned worksheet with the matching private key. The command reports pending ratings until the reviewer records a decision and rationale.
